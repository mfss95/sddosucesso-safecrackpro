# Mapeamento dos displays:
#   HEX4 -> seg_cur_pos (indice do digito ativo, 1 a 4)
#   HEX3 -> seg_pos1    (1o digito da senha)

#   HEX0 -> seg_pos4    (4o digito)
#
# Convencao do decoder bcd_to_7segment_anodo:
#   seg[6]=a seg[5]=b seg[4]=c seg[3]=d seg[2]=e seg[1]=f seg[0]=g
#   (na placa, HEXn[0]=a ... HEXn[6]=g, por isso seg[6] vai no pino de HEXn[0])
# =============================================================================
